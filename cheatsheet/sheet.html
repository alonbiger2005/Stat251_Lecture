POPULATION (parameters & claims)

$p$ = true population proportion (unknown). “the true % / proportion of all…”
$\mu$ = true population mean (unknown). “true average of all…”, “mean of the population”
$\sigma$ = population SD; $\sigma^2$ = variance. “population SD is…”, “SD = 0.04 s”; known σ → z
$p_0,\;\mu_0$ = value claimed in $H_0$ (null value). “claims 52%”, “is the mean 0.400?”
$q_0=1-p_0$ = complement of the null proportion.
$p_1-p_2,\;\mu_1-\mu_2$ = difference between groups 1 and 2. “compare A vs B”
$\mu_d$ = true mean of paired differences. “before/after on the same people”
$\Delta_0,\;d_0$ = claimed difference in $H_0$ (usually 0). “no difference”
$N$ = population size (10% condition).

SAMPLE (what the data give you)

$n$ = sample size (# in sample; paired: # of pairs). “randomly sampled 36…”
$x$ = # of “successes” (yes answers). “62 of 100 prefer…”
$\hat p=\frac{x}{n}$ = sample proportion (“p-hat”). “62% of those sampled…”
$\hat q=1-\hat p$ = sample proportion of “no”.
$\bar y\;(=\bar x)$ = sample mean (“y-bar”). “the sample averaged 0.424 s”
$s$ = sample SD; $s^2$ = sample variance. “sample standard deviation 0.060” → t
$n_1,\bar y_1,s_1,\hat p_1$ = values for group 1 (subscript 2 = group 2).
$d_i$ = one pair’s difference (e.g. after − before).
$\bar d,\;s_d$ = mean and SD of the $d_i$ list.

INFERENCE TOOLS

PE = point estimate (best single guess: $\hat p$, $\bar y$, …).
$SE$ = standard error = SD of the estimate.
$z^*,\;t^*_{df}$ = critical value from the confidence level. “95% confident”, “90% CI”
$E$ (ME, $m$) = margin of error $=c^*\times SE$. “within ±3 points”, “accurate to .01”
$C$ = confidence level; $\alpha=1-C$.
$\alpha$ = significance level (P of Type I error). “at the 5% level”, “α = .05”
$df,\;\nu$ = degrees of freedom (row of the t-table).
$z,\;t$ = test statistic (# of SEs from the null).
p-value = P(result this extreme or more | $H_0$ true).
$H_0,\;H_a$ = null (has =) / alternative ($<,>,\ne$). “test whether…”, “is there evidence…”
$\beta$ = P(Type II); power $=1-\beta$.

8CI master rule

$\text{CI}=\text{PE}\pm\underbrace{c^*\times SE}_{\text{margin of error }E}$
  1. Parameter? → PE + SE formula (table A, side 1).
  2. Critical value: proportions $z^*$ (§5), means $t^*$ (§6).
  3. $E=c^*\cdot SE$; interval $(\text{PE}-E,\;\text{PE}+E)$.
  4. Conditions (§13) + interpretation sentence.
Interpretation template: “We are 95% confident that the true [parameter in context] is between ___ and ___.” Never: “95% probability the parameter is in this interval.” Long-run meaning: 95% of intervals built this way capture the parameter.
Reading a given CI $(L,U)$: $\text{PE}=\frac{L+U}{2}$, $E=\frac{U-L}{2}$, $SE=E/c^*$, width $=2E$.
Width ↑ when confidence ↑ or $n$ ↓ or variability ↑. Width ∝ $1/\sqrt n$ (×4 $n$ → half width).

One-sided bounds ($\alpha=1-C$ in ONE tail)

lower: $(\text{PE}-c^*SE,\;\infty)$upper: $(-\infty,\;\text{PE}+c^*SE)$

$c^*$: z with left area $C$ (90% → 1.282), or t from column $\alpha$ (90% → .10 column). Professor's equivalent: negative z with left area $\alpha$, compute PE + z·SE.

All five CI formulas are in table A (side 1). $t^*_{n-1}$: subscript = df, not “t* minus 1”. Paired: $n$ = # pairs.

Difference CIs: look at 0

Contains 0 → “no difference” plausible · all > 0 → group 1 larger · all < 0 → group 1 smaller.

7Sampling distributions, SE & Welch df

$\bar Y\approx N\!\left(\mu,\dfrac{\sigma^2}{n}\right),\;SE(\bar y)=\dfrac{\sigma}{\sqrt n}\approx\dfrac{s}{\sqrt n}$$\hat p\approx N\!\left(p,\dfrac{p(1-p)}{n}\right),\;SE(\hat p)=\sqrt{\dfrac{p(1-p)}{n}}$

where $\bar Y$ = sample mean (random) · $c$ = cutoff in the question · other symbols: key on side 1.

SD = spread of individuals; SE = spread of a statistic over repeated samples. $n$ ×4 → SE ÷2.

CLT probability: $P(\bar Y>c)=1-\Phi\!\left(\frac{c-\mu}{\sigma/\sqrt n}\right)$. Practice: $\mu=.40,\sigma=.04,n=16$: SE $=.01$; $P(\bar Y>.42)=1-\Phi(2.00)=.0228$.

Sample SD (e.g. of paired $d_i$): $s=\sqrt{\dfrac{\sum(x_i-\bar x)^2}{n-1}}$

$\nu\approx\dfrac{\left(\frac{s_1^2}{n_1}+\frac{s_2^2}{n_2}\right)^2}{\frac{(s_1^2/n_1)^2}{n_1-1}+\frac{(s_2^2/n_2)^2}{n_2-1}}$ (“crazy df”)

where $s_1,s_2$ = sample SDs · $n_1,n_2$ = group sizes · $x_i$ = each data value · $\bar x$ = their mean · $\nu$ (“nu”) = Welch df.

Compute $A=s_1^2/n_1$, $B=s_2^2/n_2$ first: $\nu=(A+B)^2/\big(\tfrac{A^2}{n_1-1}+\tfrac{B^2}{n_2-1}\big)$. If allowed, conservative shortcut $df=\min(n_1,n_2)-1$.

11Hypothesis test workflow

  1. $H_0$ (has “=”, the claim/default) and $H_a$ ($<$, $>$, $\ne$) — choose before seeing data.
  2. Check conditions (§13).
  3. Test statistic = $\dfrac{\text{estimate}-\text{null value}}{SE \text{ under } H_0}$ (table A).
  4. Tail from $H_a$ → p-value from the right table.
  5. $p\le\alpha$ → reject $H_0$; $p>\alpha$ → fail to reject $H_0$.
  6. Conclusion in context.
Wording → $H_a$: “less / decreased / lower” → $<$ · “more / increased / slower(time ↑)” → $>$ · “different / changed / not equal” → $\ne$.
Conclusion template: “Since p = ___ (< or >) α = ___, we (reject / fail to reject) $H_0$. There is (enough / not enough) evidence that [$H_a$ in context].”

15MC must-knows

  • Parameter ($p,\mu$; population, unknown) vs statistic ($\hat p,\bar y,s$; sample).
  • p-value = P(data this extreme or more | $H_0$ true). It is NOT P($H_0$ true).
  • Fail to reject ≠ “accept $H_0$” / ≠ proof $H_0$ is true.
  • Type I: reject a true $H_0$ (false alarm), prob $=\alpha$. Type II: fail to reject a false $H_0$ (miss), prob $=\beta$. Power $=1-\beta$ = P(correctly reject false $H_0$).
  • Power ↑ with larger $n$, larger effect size, larger $\alpha$ (but Type I risk ↑). ↓α → ↑β.
  • Confidence level ↑ → wider CI; $n$ ↑ → narrower CI.
  • t vs z: $t$ heavier tails, depends on df; df → ∞ gives $z$.
  • CI uses $\hat p$ in SE; test uses $p_0$ in SE.
  • Continuous: $P(X=x)=0$; probability = area; density can exceed 1 (area can't).
  • Uniform flat · Exponential = time until first event (constant rate) · Normal symmetric bell.
  • $H_a$ is chosen before seeing data; tail comes only from $H_a$.

16Trap list

  • $p$ (proportion) ≠ p-value · Var vs SD in $N(\mu,\sigma^2)$ · minutes vs hours for $\lambda$.
  • z-table is LEFT area; t-table is UPPER-tail critical values — don't read t like z.
  • Two-sided: split α (.025 each tail) for CIs; double one-tail p for $\ne$ tests.
  • Paired ≠ two independent groups. Means → t, proportions → z.
  • Sample size: round up; $E$ as decimal.
  • Zero in a difference CI = no difference plausible.
